## Nota técnica
El arte final aprobado disponible es raster. Los PNG/WEBP se han exportado desde los maestros raster transparentes de mayor calidad disponibles. No se incluyen SVG falsamente presentados como vectoriales. Para impresión de gran formato conviene crear un maestro vectorial específico.

No se distribuyen archivos de fuentes.
